Mobile App - Response Visualizer

This project focuses on the development and enhancement of a smartphone application designed to serve as an interactive learning tool for analyzing linear systems modeled as transfer functions.

Developed using the Flutter framework, the app aims to modernize control education by allowing students to visualize complex concepts directly on their mobile devices.

Key features of the app include:

  • - Interactive plotting: Step response, pole–zero maps, Bode and Nyquist plots with pan/zoom controls;
  • - Real-time parameter tuning: Sliders to modify system coefficients and immediately see effects on time/frequency responses;
  • - Flexible system input: Predefined 1st/2nd order templates plus custom transfer functions up to 5th order;
  • - Comparison mode: Overlay two transfer functions to compare responses and pole/zero placements;
  • - Export & share: Save plots as images and export system parameters for reports.

Robotic Cell Simulation & Programming in ABB RobotStudio

Designed and simulated an automated manufacturing cell using ABB RobotStudio

Key achievements include:

  • - RAPID Programming: Developed the complete control logic, managing digital signals to coordinate robot movements with conveyor belts and station logic;
  • - Collision Avoidance: I implemented specific logic to manage a "shared zone," using semaphores and wait signals to prevent interference between the two arms during the assembly process;
  • - Energy Analysis: Study and analysis of the characteristic parameters of the processing phase, evaluating energy consumption, effort, and improving the layout aiming for an improvement in efficiency;

Reaction Time - Pupil Core

The objective of this study is to determine human reaction times by comparing the results obtained through the Pupil Core system with those measured using the High-Speed camera, which serves as the reference system. The aim is to quantify the deviation between the two methods and assess the reliability of the Pupil Core algorithm. This study highlights the difficulties in achieving optimal reaction time measurements.
